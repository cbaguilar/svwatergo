# S3 Utilities

This module provides a thin, shared S3 layer for reading/writing Parquet, audio, and bytes.

## Examples

### Read Parquet from S3 or local
```python
from ml.storage import read_parquet_uri

df = read_parquet_uri("s3://my-bucket/path/to/data.parquet")
```

### Read audio from S3
```python
from ml.storage import read_audio_uri

y, sr, subtype = read_audio_uri("s3://my-bucket/audio.wav")
```

### List window_features parquet sources
```python
from ml.storage import list_parquet_sources

sources = list_parquet_sources(
    s3_bucket="svwaternet",
    s3_prefix="derived",
    site="bluerock",
    dates=["2026-02-25", "2026-02-26"],
    window_s=10,
)
```
